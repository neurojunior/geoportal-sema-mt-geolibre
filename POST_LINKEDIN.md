🌎🗺️ **Geoportal SEMA-MT agora integrado ao GeoLibre Desktop**

Desenvolvi um plugin independente para facilitar o acesso da comunidade GIS às
bases geográficas públicas disponibilizadas pela **SEMA-MT**.

Com o plugin **Geoportal SEMA-MT**, é possível pesquisar e visualizar mosaicos
e bases temáticas diretamente no mapa, além de baixar os dados vetoriais
disponíveis por WFS.

Principais recursos:

✅ 182 camadas WMS para visualização;

✅ 47 mosaicos e imagens de satélite;

✅ 135 bases vetoriais WFS para download;

✅ exportação em Shapefile e GeoJSON;

✅ download da camada completa ou pela extensão do mapa;

✅ funcionamento direto no GeoLibre Desktop, sem servidor Python ou executável
adicional.

O objetivo é tornar o acesso às informações ambientais públicas mais simples,
organizado e acessível para profissionais, estudantes, pesquisadores e órgãos
que trabalham com geotecnologias em Mato Grosso.

O plugin será compartilhado gratuitamente no GitHub para uso e colaboração da
comunidade.

📌 Dados e serviços oficiais: SEMA-MT  
📌 Plataforma GIS: GeoLibre Desktop
